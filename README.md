# RaveBuilder AI

Futuristic AI-powered website generator with cyberpunk aesthetics. Built with Next.js 14, Tailwind CSS, and Mistral AI.

## Features

- **4 Template Styles**: Cyberpunk, Hardtek, Jungle, Minimal
- **AI Generation**: Mistral AI generates responsive HTML + Tailwind CSS websites
- **Dark Mode**: Full cyberpunk dark theme with neon accents
- **Mobile-First**: Responsive design optimized for all screen sizes
- **Generation History**: Browse and revisit past generations
- **Local API Key Storage**: Mistral API key stored securely in browser

## Pages

- **Dashboard** - Select a template, write a prompt, generate a website
- **My Generations** - View, preview, and delete past generations
- **Settings** - Configure your Mistral AI API key

## Tech Stack

- Next.js 14 (App Router)
- Tailwind CSS
- Supabase (generation history persistence)
- Mistral AI API (website generation)
